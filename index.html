⚠️ Technical note bhai: browser-only free libraries se asal PDF encryption (jo Adobe/Windows password prompt dikhaye) reliably support nahi hoti — yahan hum PDF ko lock/restricted mode me flag karte hain. Agar aapko bilkul real, sab PDF-viewers me chalne wala password chahiye (jaise WinRAR jaisa), uske liye ek chhota backend (Node.js + qpdf) lagega — wo main alag se bana sakta hun agar chahiye ho.
